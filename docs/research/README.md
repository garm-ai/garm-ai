# Research

A research note is a dated reading of something outside this repository — a
library, a protocol, a product — made before a spec that depends on it is
written. It records what was *read*, with versions, so the spec can cite it and a
later reader can see what was true when the decision was taken. It decides
nothing; the spec does.

Naming is `YYYY-MM-DD-<subject>.md`, with `**Date:**` and `**Status:**` on lines
3 and 4, like [../specs/](../specs/) and [../decisions/](../decisions/).
