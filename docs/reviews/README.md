# Reviews

A review is a dated reading of the whole repository against a stated bar, with
grades and an action list. It is the one document here that is allowed to be
*opinionated about the present* rather than specify the future.

Naming is `YYYY-MM-DD-<scope>-review.md`, with `**Date:**` and `**Status:**` on
lines 3 and 4 — the same shape as [../decisions/](../decisions/) and
[../specs/](../specs/).

**A review's findings go to the roadmap, not to a backlog.** Each action in a
review's list either becomes a roadmap row with its "waits on" filled in, or a
commit, or a decision record saying why not. A finding that is none of those a
month later is the review's failure to be read, and the next review should say so.
