# The run store — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tool declared `async` can be invoked: the caller gets `pending{run_id}`
once the run is durable, a `rund` replica executes it from a DBOS queue, and
`Fetch` — with an optional capped `wait` — returns its state, outcome and stage,
to the invoking account only. Sync calls never touch the store and keep working
when it is unreachable.

**Architecture:** `run.Store` is the port (two verbs, `Start` and `Fetch`); the
engine uses it only for async tools. `rundbos` is the one DBOS importer: one
registered workflow `invoke` whose body is the engine's plan loop with each tool
call as a `RunAsStep` under deterministic ids; a queue `runs`; a stable executor
id for recovery; a degraded wrapper when the store is down. The wire grows
additively. The generated client gains async methods and a `call.Ref`. The estate
runs DBOS on in-memory SQLite; `compose.yaml` gains Postgres.

**Tech Stack:** Go 1.26.6 (`mise exec -- go`) · `github.com/dbos-inc/dbos-transact-golang`
**v1.5.0** (+ `dbos/driver/sqlite`, pure Go) · protobuf (`google/protobuf/duration.proto`,
`timestamp.proto`) · `buf` · Postgres 17 in compose.

**Spec:** [docs/specs/2026-10-05-run-store-design.md](../specs/2026-10-05-run-store-design.md)
— §10 properties, §11 order, §9 decisions. Research it cites:
[docs/research/2026-10-05-dbos-go-sdk.md](../research/2026-10-05-dbos-go-sdk.md).

## Global Constraints

- **A property is not trusted until it has been proved to fail.** Break the
  mechanism, watch the test fail, `git checkout --` restore — **on a clean tree
  only; commit before probing**.
- **Only `rundbos` imports `dbos-inc`.** `run`, `rundsvc`, `natscall`, `call`, the
  generated code import nothing from it; `mise run no-sdk` gains the line (Task 1)
  so it bites the moment Task 3 adds the dependency.
- **A sync call touches no store.** `Engine.Invoke` for a sync tool is the code
  path of today, byte for byte in behaviour; property 13 pins it.
- **The envelope is stored with the run; message ids inside a run are
  deterministic** (`run.StepHeaders`). No `e.id()` inside the workflow.
- **No payload in an event, attribute or log.** `stage` is a word and a reference.
- **Wire changes are additive**; `buf breaking` stays green.
- **Credentials are never logged** — the store URL in the startup line is
  redacted (property 15), same rule as OTLP headers.
- **Docs move in the same commit as the fact they state.**
- `mise exec -- go` always; the shell's `go` is the wrong version.

```go
package run

import (
	"context"
	"crypto/sha256"
	"encoding/hex"
	"errors"
	"fmt"
	"time"

	invokev1 "github.com/garm-ai/garm-ai/garm/invoke/v1"
)

// Store is the engine's view of durability (spec §1). One implementation is DBOS
// (package rundbos); nil is none -- sync only, today's rund. The engine never
// imports an implementation.
type Store interface {
	// Start makes the run durable and returns once it is. ID is the caller's
	// idempotency key; a second Start with the same key and the same fingerprint
	// returns the same run (Existing) and starts nothing.
	Start(ctx context.Context, r Run) (Started, error)
	// Fetch answers for a run. wait > 0 blocks until the state or the stage
	// changes or wait elapses; the engine clamps wait to MaxFetchWait first.
	// ErrNotFound for an id the store has never seen.
	Fetch(ctx context.Context, id string, wait time.Duration) (State, error)
}

// MaxFetchWait caps a Fetch's wait: a request must never outlive the bus's own
// timeouts, and a thousand front doors waiting are goroutines here, not pollers.
const MaxFetchWait = 30 * time.Second

// ErrNotFound: the store has never seen this id. The engine turns it -- and a
// run owned by another account -- into NOT_FOUND, indistinguishably.
var ErrNotFound = errors.New("run: no such run")

type Status int

const (
	StatusUnknown Status = iota
	StatusRunning        // pending in the queue, or executing: the caller's view is one state
	StatusSucceeded
	StatusFailed
	StatusCancelled
)

// Run is what Start makes durable: the request, and the ENVELOPE the caller
// sent, kept with the run because execution happens later, on another replica,
// when the request is long gone (spec §6.1).
type Run struct {
	ID          string // the idempotency key, required
	Tool        string
	Input       []byte
	Fingerprint string // Fingerprint(Tool, Input)
	Caller      string // the invoking account's public key
	CallerName  string // its label, if known
	Attributes  map[string]string
	Correlation string // the caller's, or the run id if it sent none
	Message     string // the caller's message id: the causation of step 0
	Traceparent string // continued by the step that executes
}

type Started struct {
	ID       string
	Existing bool
}

type State struct {
	ID          string
	Status      Status
	Stage       string
	Result      []byte
	Error       *invokev1.Error
	Caller      string
	CreatedAt   time.Time
	CompletedAt time.Time
}

// Fingerprint binds a key to the request it was used for: sha256 over the tool
// name, a NUL, and the input bytes -- the separator so "ab"+"c" and "a"+"bc" are
// not the same request.
func Fingerprint(tool string, input []byte) string {
	h := sha256.New()
	h.Write([]byte(tool))
	h.Write([]byte{0})
	h.Write(input)
	return hex.EncodeToString(h.Sum(nil))
}

// StepHeaders is the envelope a run's step i carries, DETERMINISTICALLY: a
// replayed step re-sends the same message id, so the trail shows one cause and
// the tool's idempotency check collapses the duplicate (spec §6.1). Step 0 is
// caused by the caller's message; step i by step i-1's.
func StepHeaders(r Run, i int) Headers {
	id := func(i int) string {
		sum := sha256.Sum256([]byte(fmt.Sprintf("%s:%d", r.ID, i)))
		return hex.EncodeToString(sum[:8])
	}
	causation := r.Message
	if i > 0 {
		causation = id(i - 1)
	}
	return Headers{
		Correlation: r.Correlation,
		Causation:   causation,
		Message:     id(i),
		Traceparent: r.Traceparent,
		Idempotency: fmt.Sprintf("%s:%d", r.ID, i),
	}
}
```

```go
// startAsync is the async path: nothing executes here. The run is made durable
// and the caller gets its id; a replica executes it from the queue (spec §2).
func (e *Engine) startAsync(ctx context.Context, tool declared.Tool, req *runv1.InvokeRequest, h Headers) (*runv1.InvokeResponse, *invokev1.Error) {
	if h.Idempotency == "" {
		// rund minting the key would make a retry a second run -- the opposite
		// of idempotent (spec §6). A model never sets one; the decider does.
		return nil, e.fail(ctx, "", h, tool.Name, serve.Invalid(
			"%s is async: an idempotency key is required (Garm-Idempotency-Key), and it becomes the run id", tool.Name))
	}
	if e.Store == nil {
		return nil, e.fail(ctx, h.Idempotency, h, tool.Name, serve.Unavailable(
			"%s is declared async and this rund has no run store; start it with --run-store", tool.Name))
	}
	r := Run{
		ID: h.Idempotency, Tool: tool.Name, Input: req.GetInput(),
		Fingerprint: Fingerprint(tool.Name, req.GetInput()),
		Caller: h.Caller, CallerName: h.CallerName,
		Attributes:  map[string]string{"correlation": h.Correlation},
		Correlation: h.Correlation, Message: h.Message, Traceparent: h.Traceparent,
	}
	if r.Correlation == "" {
		r.Correlation = r.ID
	}
	started, err := e.Store.Start(ctx, r)
	if err != nil {
		return nil, e.fail(ctx, r.ID, h, tool.Name, err)
	}
	e.log().InfoContext(ctx, "run started", "run", started.ID, "tool", tool.Name, "existing", started.Existing,
		"correlation", r.Correlation, "caller", h.Caller)
	return &runv1.InvokeResponse{RunId: started.ID, Outcome: &runv1.InvokeResponse_Pending{Pending: &runv1.Pending{}}}, nil
}
```

`Fetch` gains the headers and the store:
```go
func (e *Engine) Fetch(ctx context.Context, req *runv1.FetchRequest, h Headers) (*runv1.FetchResponse, *invokev1.Error) {
	if req.GetRunId() == "" {
		return nil, serve.Wire(serve.Invalid("run_id is required"), "")
	}
	if e.Store == nil {
		return &runv1.FetchResponse{State: runv1.RunState_RUN_STATE_NOT_RETAINED}, nil
	}
	wait := req.GetWait().AsDuration()
	if wait > MaxFetchWait {
		wait = MaxFetchWait
	}
	st, err := e.Store.Fetch(ctx, req.GetRunId(), wait)
	switch {
	case errors.Is(err, ErrNotFound):
		return nil, serve.Wire(serve.NotFound("no run %s", req.GetRunId()), "")
	case err != nil:
		return nil, e.fail(ctx, req.GetRunId(), h, "", err)
	}
	// Visibility (spec §4): the first body of the function the authority model
	// will replace. A foreign run is NOT_FOUND, not DENIED -- its existence is
	// not the caller's to learn.
	if !e.visible(h, st) {
		return nil, serve.Wire(serve.NotFound("no run %s", req.GetRunId()), "")
	}
	resp := &runv1.FetchResponse{State: wireState(st.Status), Stage: st.Stage}
	if !st.CreatedAt.IsZero() { resp.CreatedAt = timestamppb.New(st.CreatedAt) }
	if !st.CompletedAt.IsZero() { resp.CompletedAt = timestamppb.New(st.CompletedAt) }
	switch {
	case st.Error != nil:
		resp.Outcome = &runv1.FetchResponse_Error{Error: st.Error}
	case st.Status == StatusSucceeded:
		resp.Outcome = &runv1.FetchResponse_Result{Result: st.Result}
	}
	return resp, nil
}

// visible: may this principal see this run? Today: the invoking account, and
// nobody else. The authority model replaces this body; its callers do not change.
func (e *Engine) visible(h Headers, st State) bool { return h.Caller != "" && h.Caller == st.Caller }

func wireState(s Status) runv1.RunState { /* StatusRunning→RUNNING, Succeeded→SUCCEEDED, Failed→FAILED, Cancelled→CANCELLED, else UNSPECIFIED */ }
```

```go
		Logger: cfg.Logger, SkipMigrations: !cfg.Migrate,
	})
	if err != nil { return nil, fmt.Errorf("rundbos: %w", err) }
	dbos.RegisterWorkflow(dctx, s.invoke, dbos.WithWorkflowName(WorkflowName))
	q, err := dbos.RegisterQueue(dctx, QueueName, dbos.WithWorkerConcurrency(cfg.Workers))
	if err != nil { return nil, fmt.Errorf("rundbos: %w", err) }
	if err := dbos.Launch(dctx); err != nil { return nil, fmt.Errorf("rundbos: launch: %w", err) }
```

```go
	if r.ID == "" { return run.Started{}, serve.Invalid("a run needs an idempotency key") }
	// Known key? Then the fingerprint decides: same request, same run; different
	// request, refused -- before DBOS's "new input is ignored" can bite (spec §6).
	if h, err := dbos.RetrieveWorkflow[outcome](s.ctx, r.ID); err == nil {
		st, err := h.GetStatus()

		if fp, _ := st.Attributes["fingerprint"].(string); fp != r.Fingerprint {
```

```go
func (s *Store) state(h dbos.WorkflowHandle[outcome]) (run.State, error) {
	st, err := h.GetStatus()
	if err != nil { return run.State{}, storeErr(err) }
	out := run.State{ID: st.ID, Caller: st.AuthenticatedUser, CreatedAt: st.CreatedAt, CompletedAt: st.CompletedAt}
	switch st.Status {
	case dbos.WorkflowStatusSuccess:
		out.Status = run.StatusSucceeded
		res, err := h.GetResult(dbos.WithHandleTimeout(time.Second)) // completed: returns at once
		if err != nil { return run.State{}, storeErr(err) }
		if res.Error != nil { out.Status, out.Error = run.StatusFailed, res.Error } else { out.Result = res.Result }
	case dbos.WorkflowStatusError:
		out.Status, out.Error = run.StatusFailed, wireOf(st.Error) // a panic or an infrastructure error: INTERNAL
	case dbos.WorkflowStatusCancelled:
		out.Status = run.StatusCancelled
	default:
		out.Status = run.StatusRunning
	}
	return out, nil
}
```

```go
// error, as a value. A Go error from the workflow means the RUN could not be
// executed; a tool saying INVALID is an answer, and it is recorded as one.
type outcome struct {
	Result []byte
	Error  *invokev1.Error
}

// plan is step 0's checkpoint: the actions the run will take, or the refusal
// planning produced. run.Action must round-trip JSON (Tool, Input, Budget).
type plan struct {
	Actions []run.Action
	Error   *invokev1.Error
}

// invoke is the engine's plan loop made durable: one step per action, each
// under deterministic headers (run.StepHeaders), the stage set before each.
func (s *Store) invoke(ctx dbos.Context, r run.Run) (outcome, error) {
	// Step 0 is the plan. The catalogue is consulted ONCE, and the action list
	// is checkpointed with the run: a replay after a catalogue change (the tool
	// renamed, its budget changed, the tool gone) follows the plan the run was
	// started with, not whatever the catalogue says now. That is DBOS's
	// determinism rule applied to our one source of non-determinism -- and it is
	// the same mechanism a workflow runner needs for its pinned graph.
	planned, err := dbos.RunAsStep(ctx, func(context.Context) (plan, error) {
		tool, ok := s.cat.Current().Tool(r.Tool)
		if !ok {
			return plan{Error: serve.Wire(serve.NotFound("no tool named %q in the catalogue", r.Tool), r.ID)}, nil
		}
		actions, err := run.Plan(tool, r.Input)
		if err != nil {
			return plan{Error: serve.Wire(err, r.ID)}, nil
		}
		return plan{Actions: actions}, nil
	}, dbos.WithStepName("plan"), dbos.WithStepMaxRetries(0))
	if err != nil {
		return outcome{}, err
	}
	if planned.Error != nil {
		return outcome{Error: planned.Error}, nil
	}
	actions := planned.Actions
	var last []byte
	for i, a := range actions {
		if err := dbos.SetEvent(ctx, "stage", fmt.Sprintf("calling:%d", i)); err != nil {
			return outcome{}, err
		}
		h := run.StepHeaders(r, i)
		out, err := dbos.RunAsStep(ctx, func(c context.Context) ([]byte, error) {
			c = continueTrace(c, r.Traceparent)
			return s.tools.Call(c, a.Tool, a.Input, a.Budget, h)
		}, dbos.WithStepName(h.Idempotency), dbos.WithStepMaxRetries(StepAttempts-1),
			dbos.WithStepRetryPredicate(func(err error) bool { return observe.Kind(err) == "UNAVAILABLE" }))
		if err != nil {
			var se *serve.Error
			if errors.As(err, &se) || errors.Is(err, dbos.ErrMaxStepRetriesExceeded) {
				// The tool's own kind -- after bounded retries for UNAVAILABLE.
				return outcome{Error: serve.Wire(unwrapStep(err), r.ID)}, nil
			}
			return outcome{}, err // cancelled, or DBOS itself
		}
		last = out
	}
	_ = dbos.SetEvent(ctx, "stage", "done")
	return outcome{Result: last}, nil
}
```
`continueTrace` extracts the stored `traceparent` into `c` with the OTel propagator and starts no span (the tool caller's own `garm.tool` span is the child). `unwrapStep` finds the `*serve.Error` inside DBOS's wrapping (`errors.As` through `ErrMaxStepRetriesExceeded`'s cause). Check `ErrMaxStepRetriesExceeded` wraps the last error (`errors.go` / `workflow.go` around retries) and adjust.

**`outcome` must round-trip through DBOS's JSON serializer**: `[]byte` → base64, `*invokev1.Error` → its JSON (protobuf structs marshal with `encoding/json` via exported fields; `enum` as a number) — a test `TestOutcomeRoundTrips` in `rundbos_test.go` pins it, because a silent serializer mismatch would surface as a run that "succeeded" with a nil result.

```go
func (s *Store) Fetch(ctx context.Context, id string, wait time.Duration) (run.State, error) {
	h, err := dbos.RetrieveWorkflow[outcome](s.ctx, id)
	if errors.Is(err, dbos.ErrNonExistentWorkflow) { return run.State{}, run.ErrNotFound }
	if err != nil { return run.State{}, storeErr(err) }
	first, err := s.state(h)
	if err != nil || wait <= 0 || first.Status != run.StatusRunning { return first, err }
	// Wait for completion (DBOS's blocking read) OR a stage change (a cheap poll
	// on the event), whichever first, within wait.
	done := make(chan struct{})
	go func() { _, _ = h.GetResult(dbos.WithHandleTimeout(wait)); close(done) }()
	deadline := time.Now().Add(wait)
	tick := time.NewTicker(200 * time.Millisecond)
	defer tick.Stop()
	for {
		select {
		case <-done:
			return s.state(h)
		case <-ctx.Done():
			return first, nil
		case <-tick.C:
			if time.Now().After(deadline) { return s.state(h) }
			cur, err := s.state(h)
			if err != nil { return run.State{}, err }
			if cur.Stage != first.Stage || cur.Status != run.StatusRunning { return cur, nil }
		}
	}
}
```
