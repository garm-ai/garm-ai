# Push — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A run's events — `stage`, `step`, `done` — are recorded in a DBOS
stream with sequence numbers, published live on an account-token stream export
only the run's owner can import, readable after the fact with `Events(run_id,
after, wait)`, and followed from a generated client's `Ref` with catch-up and
live stitched by sequence number. `garmctl fetch --follow` shows it; the quick
start proves live and catch-up.

**Architecture:** `rundbos`'s workflow gains one `emit` step: write the event to
the DBOS stream (durable, fails the run if it fails), then publish the live copy
through a `Live` publisher (best effort, counted, never fails the run).
`run.Store` gains `Events`; `run.Engine` gains `Events` with the same ownership
check as `Fetch`; `rundsvc` mounts `garm.run.v1.*.events` and provides the
publisher. The generator derives the stream export and the per-caller import.
`call.Ref.Follow` does the stitch once. The wire is additive.

**Tech Stack:** Go 1.26.6 (`mise exec -- go`) · DBOS Go SDK v1.5.0 (`WriteStream`,
`ReadStream` with `WithReadStreamFromOffset`, `CloseStream`) · NATS stream
exports with `AccountTokenPosition` · protobuf · `buf`.

**Spec:** [docs/specs/2026-10-07-push-design.md](../specs/2026-10-07-push-design.md)
— §10 properties 1–18, §11 order, §9 decisions.

## Review Focus

1. **`Follow` started with the cursor exactly at the last event**, and the run
   already closed. Expected: yields nothing and returns, no hang. Task 4
   (`TestFollowFromTheEndOfAClosedRunReturnsAtOnce`).
2. **An `Events` request with `after` beyond the stream's end** (a stale cursor
   from a different run id reused). Expected: an empty reply, `closed` as the
   stream is, no error, no hold past the cap. Task 2
   (`TestEventsPastTheEndIsEmptyNotAnError`).
3. **Two events written faster than the live subscriber reads**, so the live
   buffer holds both when the catch-up batch returns. Expected: each yielded
   once, in order. Task 4's mid-run test blocks the tool so the boundary is
   inside the run; this case adds a second blocked step (`gates` on `k:0` and
   `k:1`) — `TestFollowKeepsOrderAcrossTwoLiveEventsBehindTheCatchUp`.
4. **A run whose owner is the empty string** (a run started with no proven
   caller — deferred minor 11 of the run-store review). Expected: `rund`
   publishes nothing for it (no subject can carry an empty token) and logs
   once; `Events` is `NOT_FOUND` for everyone, as `Fetch` is. Task 3
   (`TestARunWithNoOwnerIsPublishedToNobody`).
5. **The stream export's local subject colliding with the service import's
   prefix** (`garm.run.v1.out.>` lies inside `garm.run.v1.>`). Expected: a
   caller can still invoke and fetch, and receives its events; proved on the
   real bus in Task 3 before anything else in that task. If the server refuses
   the overlap, the ruling is a sibling prefix `garm.out.v1.>` on the local side
   only, and the spec's §2 is amended.

```go
// run/run.go
// Events is the run's record, after a cursor. The same ownership as Fetch: the
// run's state is read first and a foreign or unknown run is NOT_FOUND, so the
// stream of a run the caller may not see is never read.
func (e *Engine) Events(ctx context.Context, req *runv1.EventsRequest, h Headers) (*runv1.EventsResponse, *invokev1.Error) {
	if req.GetRunId() == "" {
		return nil, serve.Wire(serve.Invalid("run_id is required"), "")
	}
	if e.Store == nil {
		return &runv1.EventsResponse{Closed: true}, nil // no record was kept
	}
	st, err := e.Store.Fetch(ctx, req.GetRunId(), 0)
	switch {
	case errors.Is(err, ErrNotFound):
		return nil, serve.Wire(serve.NotFound("no run %s", req.GetRunId()), "")
	case err != nil:
		return nil, e.fail(ctx, req.GetRunId(), h, "", err)
	}
	if !e.visible(h, st) {
		return nil, serve.Wire(serve.NotFound("no run %s", req.GetRunId()), "")
	}
	wait := req.GetWait().AsDuration()
	if wait > MaxFetchWait {
		wait = MaxFetchWait
	}
	events, closed, err := e.Store.Events(ctx, req.GetRunId(), req.GetAfter(), wait)
	if err != nil {
		return nil, e.fail(ctx, req.GetRunId(), h, "", err)
	}
	return &runv1.EventsResponse{Events: events, Closed: closed}, nil
}
```

```go
// emit records one event -- the durable act -- and then offers it live. The
// record is the workflow's; a failed write fails the step and the run, because
// a run with no record of what it did is not a run this platform keeps. The
// live copy is best effort: a publish that fails is counted and logged, never
// returned, because a subscriber that missed it has the record. Both inside
// ONE step, so a replay neither rewrites nor republishes.
func (s *Store) emit(ctx dbos.Context, r run.Run, kind any) error {
	ev := &runv1.Event{RunId: r.ID, At: timestamppb.Now()}
	switch k := kind.(type) {
	case *runv1.Stage:    ev.Kind = &runv1.Event_Stage{Stage: k}
	case *runv1.Step:     ev.Kind = &runv1.Event_Step{Step: k}
	case *runv1.Done:     ev.Kind = &runv1.Event_Done{Done: k}
	case *runv1.Progress: ev.Kind = &runv1.Event_Progress{Progress: k}
	case *runv1.Question: ev.Kind = &runv1.Event_Question{Question: k}
	case *runv1.Chunk:    ev.Kind = &runv1.Event_Chunk{Chunk: k}
	}
	if err := CheckEvent(ev); err != nil {
		return err
	}
	_, err := dbos.RunAsStep(ctx, func(c context.Context) (uint64, error) {
		// The sequence is the stream's position: written once, read back by
		// the reader as offset+1. WriteStream inside a step is DBOS's own
		// durable write; the step wraps it with the publish so a replay skips both.
		if err := dbos.WriteStream(ctx, StreamKey, ev); err != nil {
			return 0, err
		}
		seq, err := s.streamLength(ctx, r.ID) // ReadStream len, after the write: the position of this event
		if err != nil {
			return 0, err
		}
		ev.Seq = seq
		if s.live != nil && r.Caller != "" {
			if b, err := proto.Marshal(ev); err == nil {
				if err := s.live.Publish(r.Caller, r.ID, seq, b); err != nil {
					s.log.Warn("live event not delivered", "run", r.ID, "seq", seq, "error", err)
					s.count("dropped")
				} else {
					s.count("delivered")
				}
			}
		}
		return seq, nil
	}, dbos.WithStepName(fmt.Sprintf("emit:%d", r.ID /* plus a per-run counter */)), dbos.WithStepMaxRetries(0))
	return err
}
```
**Find out at Step 3 and ledger it:** whether `WriteStream` may be called inside `RunAsStep` (it takes the workflow `dbos.Context`, and a step runs with a `context.Context`). If it may not — the SDK says "can only be called from within a workflow" — the shape is: `WriteStream` at workflow level (its own durable op), then the publish in a `RunAsStep` named `publish:<seq>`; a replay re-executes neither. Then `Seq` is `ReadStream` length after the write, at workflow level, which is deterministic on replay because the stream is part of the workflow's state. Either way the two properties hold: record first, live never fails the run, nothing repeats on replay. The step name carries a per-run counter (`emitN`) kept in the workflow's locals, which replay rebuilds.

The `invoke` workflow then: `emit(stage calling:i)` before each step (keeping `SetEvent` for the latest word), `emit(step{key, kind, tool})` after it, `emit(stage done)`, `emit(done{state})`, then `dbos.CloseStream(ctx, StreamKey)`. The cancel path: when `ctx.Err() != nil` after a step, `emit(done{CANCELLED})` on an uncancellable child of the DBOS context — **find out** whether DBOS lets a cancelled workflow write a stream; if not, `done CANCELLED` is synthesised by the READER from the run's `CANCELLED` status as a final event with `Seq = len+1`, and property 9's test accepts either, ledgered. `CheckEvent` validates the chunk cap.

```go
func (s *Store) Events(ctx context.Context, id string, after uint64, wait time.Duration) ([]*runv1.Event, bool, error) {
	sess, err := s.session()
	if err != nil { return nil, false, err }
	read := func() ([]*runv1.Event, bool, error) {
		vals, closed, err := dbos.ReadStream[*runv1.Event](sess.ctx, id, StreamKey, dbos.WithReadStreamFromOffset(int(after)))
		if err != nil { return nil, false, s.storeErr(sess, err) }
		if len(vals) > run.MaxEventsBatch { vals = vals[:run.MaxEventsBatch]; closed = false }
		for i, v := range vals { v.Seq = after + uint64(i) + 1 }
		return vals, closed, nil
	}
	evs, closed, err := read()
	if err != nil || len(evs) > 0 || closed || wait <= 0 { return evs, closed, err }
	deadline := time.Now().Add(wait)
	tick := time.NewTicker(StagePoll)
	defer tick.Stop()
	for {
		select {
		case <-ctx.Done():
			return nil, false, nil
		case <-tick.C:
			evs, closed, err = read()
			if err != nil || len(evs) > 0 || closed || time.Now().After(deadline) { return evs, closed, err }
		}
	}
}
```
